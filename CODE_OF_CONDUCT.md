# Code of Conduct

[English](CODE_OF_CONDUCT.md) | [한국어](CODE_OF_CONDUCT.ko.md)

Everyone participating in this project is expected to:

- be respectful and considerate when discussing code and ideas;
- provide constructive feedback and accept good-faith corrections;
- welcome contributors with different backgrounds and experience levels;
- respect personal information and private communications.

Harassment, discrimination, threats, sexualized conduct, and publishing
another person's private information without permission are not acceptable.

Maintainers may edit or remove inappropriate contributions, close disruptive
discussions, or restrict participation when needed to protect the community.
Enforcement should consider context and aim for a fair, proportionate response.

Raise community concerns with the repository owner, [@jisung-02](https://github.com/jisung-02).
For a sensitive matter, request a private contact without posting personal
details publicly. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
