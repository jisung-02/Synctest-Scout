# Getting help

[English](SUPPORT.md) | [한국어](SUPPORT.ko.md)

Start with the [README](README.md), `synctest-scout help`, and
`synctest-scout help fix` for supported commands and known limitations.

For a reproducible bug, open a [bug report](https://github.com/jisung-02/Synctest-Scout/issues/new?template=bug_report.yml).
For a proposed improvement, use the [feature request form](https://github.com/jisung-02/Synctest-Scout/issues/new?template=feature_request.yml).
General usage questions can be opened as issues with the relevant command,
Go version, operating system, and a small example.

Do not include credentials, private repository contents, or sensitive logs.
See [SECURITY.md](SECURITY.md) for vulnerability reporting.

This is a community-maintained project. Support is provided on a best-effort
basis, without a service-level agreement.
